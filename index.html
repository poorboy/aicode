aicode 是一个轻量级 AI 任务批处理系统。它在 Web 上管理 项目、任务分组 与 任务，把「提示词 + 项目目录」组织成任务队列， 并行在 codetools（Go 版 opencode 重写）引擎上创建会话、发送提示词， 并在浏览器里实时观看 AI 输出，任务完成自动导出 Markdown 会话存档。

功能特性

为「批量驱动 AI 编码」而生的每一块拼图

从任务编排、引擎实例调度，到实时输出、失败自愈、知识检索与容器构建， 你需要的环节都已经在同一个程序里跑通。

任务编排与串行执行

项目 / 任务分组 / 任务三层对象；按 order 严格串行执行——本版本同一时间 只运行 1 个任务（并发数不可配置），支持批量操作与任务模板。

  • 任务 = 标题 + 提示词模板（$TASKDES 代入）
  • 一个项目目录可关联任意多个任务
  • 一键「开始执行 / 停止」，逐个会话 abort

SSE 实时输出

任务运行中打开聊天窗口，通过 SSE 实时查看 AI 的文本、工具调用与推理过程， 随时介入继续对话，完成后再自动落盘 Markdown 会话存档。

  • 每项目目录一个独立引擎实例，同目录任务复用
  • 卡死检测 / 自动续推 / 活跃静默宽限
  • 进程安全：只终止自己启动的实例

备用代理自动切换

任务可配置有序「备用代理列表」：主代理命中限流、额度用尽、首条回复超时或流式挂起时 立即切换下一个，并在同一会话续做，已产出内容不丢失。

  • provider 定义启动时合并，切换只 PATCH 会话模型
  • 全部代理失败再走指数退避兜底
  • 代理额度统计按实际生效模型记录

HTTP 代理池与限流重试

「HTTP 代理列表」不切换模型，只把请求经代理列表依次发出；引擎在单次请求命中 429/5xx 或网络错误时自动换下一个代理重试，与模型级重试形成双层自愈。

  • 支持 http:// https:// socks5://
  • 限流重试：30s×2ⁿ 指数退避，封顶 5 分钟
  • 任务列表显示「备用 N」「HTTP 代理 N」徽标

代码图谱 CodeGraph

按「用户 × 项目」独立落盘索引文件与查询库，提供索引后台任务、状态统计、 符号搜索、影响面分析与图谱视图，让 AI 与人都能快速定位改动范围。

  • /api/codegraph/* 与 /tk 变体
  • jobs 轮询 / 停止 / 删除，索引结果可追溯

容器构建环境

程序部署在容器里、容器内没有编译工具链时，通过 Docker Engine 在一次性容器中执行 go build / npm run build / pytest， 目录 bind mount 共享，产物自动回落到源码目录。

  • lin_env 环境容器池与 buildenv 快速构建
  • 增量输出轮询、同步 / 异步执行、产物浏览下载

技能与技能市场

全局技能目录 data/skills/，Web 端 zip 导入 / 导出 / 删除 / 预览， 安装或删除即时同步到运行中的引擎实例；可对接 SkillHub 技能市场。

  • 内置 op-task、container-build 等技能模板
  • 技能改动无需重启实例

多用户与授权

多用户数据隔离、管理员 / 普通用户角色、登录与授权码保护、x-tk 程序化访问令牌，以及不可关闭的强制授权与授权服务器自动激活。

  • 项目、知识库集合、实例按用户隔离
  • 授权文件 / 外部授权服务器两种路线

运维与集群

在线自更新（二进制 + Web 静态资源）、集群总后台上报、授权服务器客户机、 运行日志与代理额度统计，多节点部署也能统一管理。

  • /api/update* 自更新（update_key 鉴权）
  • cluster.enabled 状态上报与代理调用

文件浏览与终端

以项目目录为根在线浏览 / 上传 / 下载 / 预览 / 编辑 / 删除文件（服务端防路径穿越）， 并内置 Web bash 命令终端，运维和调试不必再登服务器。

  • shell.enabled 一键开关终端页
  • Monaco 编辑器在线改文件
工作流程

六步跑完一轮 AI 批量编码

从建项目到拿到会话存档，全流程都在同一个 Web 控制台里闭环。

  1. 01

    建项目

    一个项目对应一个磁盘目录；用 Web 表单或 /api/projects 登记目录，并可做目录可用性检查。

  2. 02

    建分组与任务

    任务分组负责串行编排；任务填写标题与提示词模板，选择项目、分组与执行顺序。

  3. 03

    配置 AI 与自愈

    选定主代理模型，可选备用代理列表、HTTP 代理列表，以及限流重试与卡死检测参数。

  4. 04

    开始执行

    点击「开始执行」，系统按并发度调度任务，为每个项目目录拉起独立的 codetools 实例。

  5. 05

    实时观看与介入

    SSE 聊天窗口展示文本 / 工具调用 / 推理过程；可随时停下、继续对话或终止生成。

  6. 06

    存档与检索

    任务完成自动导出 Markdown 会话记录；产出可直接进入 CodeGraph 索引，供后续任务检索复用。

快速开始

三步启动，十分钟上手

源码构建脚本、直接运行、或者用容器环境编译 —— 挑你顺手的那条路。

# 依赖：Go ≥ 1.23；构建前端需 Node ≥ 18
# Linux / macOS
./script/setup.sh

# Windows
script/setup.bat

# 或者一键构建（自动注入编译版本信息）
sh ./bld.sh            # 产物到 exe/
cd prog && sh bld.sh    # 产物到 prog/exe/
# 启动（Windows 为 aicode.exe；Linux/macOS 为 aicode）
cd prog/exe && ./aicode.exe

# 浏览器打开控制台
http://127.0.0.1:8090

# 首次启动自动生成 data/cfg/cfg.yaml，可改端口 / 授权码 /
# aicode.base_port 等；前端开发模式（热更新）：
cd prog/lai_coding_web && npm run dev   # 默认 3000，/api 代理到 8090
# 创建项目
curl -X POST http://127.0.0.1:8090/api/projects \
  -H "Content-Type: application/json" \
  -d '{"name":"myapp","directory":"/path/to/myapp"}'

# 创建任务（关联项目，可多个任务指向同一项目）
curl -X POST http://127.0.0.1:8090/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"生成 API 文档","prompt":"请为 backend 包生成 README",
       "project_id":"project_xxx","order":1}'

# 串行执行 / 只跑某个分组 / 查看状态
curl -X POST http://127.0.0.1:8090/api/tasks/run
curl -X POST http://127.0.0.1:8090/api/groups/group_xxx/run
curl http://127.0.0.1:8090/api/tasks/status
# 程序跑在容器里、容器没有 Go/Node 工具链时：
# 走后台容器环境执行编译（container-build 技能）
TK="<程序化访问令牌>"
BASE="http://127.0.0.1:8090"

# 在 auto-go 环境里构建（产物写 /out，即落在源码目录）
curl -s -X POST -H "x-tk: $TK" -H "Content-Type: application/json" \
  -d '{"env_id":"auto-go","directory":"/work/myproj",
       "command":"go build -o /out/app ."}' \
  "$BASE/api/tk/linenv/runs?sync=1"

# 长任务异步提交后轮询增量输出 / 取产物
curl -s -H "x-tk: $TK" "$BASE/api/tk/linenv/runs/$RUN_ID?since=0"
curl -s -H "x-tk: $TK" "$BASE/api/tk/linenv/artifacts?path=build"

常见问题

上手前最常被问到的几件事

多个任务指向同一个项目目录会互相干扰吗？

不会。同一个目录的任务共享同一个引擎实例（复用端口）， 不同目录各自启动独立实例；调度上严格串行——本版本同一时间只运行 1 个 任务（并发度固定为 1，不可配置）。

模型限流（HTTP 429 / FreeUsageLimitError）会直接让任务失败吗？

默认不会。命中限流时会在同一会话内按指数退避重发一条简短系统提醒续做： 间隔 retry_backoff × 2ⁿ（默认 30s 起步，单次封顶 5 分钟）， 最多 retry_count 次（默认 8，硬上限 12，总窗口约 27 分钟）。 若配置了备用代理列表，还会先立即切换到下一个代理。

「备用代理列表」和「HTTP 代理列表」有什么区别？

备用代理列表切换的是模型 / 代理提供方（主代理不可用时换下一个模型配置）； HTTP 代理列表不换模型，只是把请求经不同正向代理发出， 命中限流或网络错误时由引擎自动换下一个代理重试。

程序部署在容器里、容器没有 Go/Node，怎么编译项目？

启用容器构建能力后，通过后台的 /api/tk/linenv/runs 在预置环境容器 （auto-go / auto-node / auto-python-pytest …）里执行编译测试命令： 项目目录 bind mount 进容器，产物写 /out 即回落到源码目录， 支持同步取全文或异步轮询增量输出，并可经 artifacts 接口浏览下载。

本宣传页需要构建吗？

不需要。 prog/webset/ 是零依赖的纯静态站点（HTML + CSS + 原生 JS）， 直接用浏览器打开 index.html 即可，也可以放进任意 Web 服务器或 本程序 static/ 目录下托管。

强制授权可以关闭吗？

不可以。未安装有效授权文件（data/license.key）时业务功能锁定、前端显示激活界面。 激活方式二选一：传统独立授权文件流程，或配置授权服务器自动激活。
